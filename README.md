# fluffy-train

ProBeat Studio is a beginner-friendly music editing web app prototype.

## Features
- Audio import and playback
- Video import for music-video sync practice
- Editing controls (trim start/end, volume, speed)
- Beginner-focused noise cancellation and autotune intensity controls
- Built-in instrument note player
- Beat generator with BPM control
- Simple track builder for project organization
- "Pro Starter" preset to help beginners get professional-sounding defaults

## Run locally
Because this is a static web app, you can run it with any simple local server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
